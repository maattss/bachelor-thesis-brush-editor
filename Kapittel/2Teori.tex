\section{Git og Github}
En viktig del av ethvert større utviklingsprosjekt er bruken av versjonskontroll. I dette prosjektet ble Github brukt som plattform. Versjonskontrollen gjør samarbeid under utviklingen mye enklere. Dette prosjektet er bygget opp av to hovedgrener: «Master» og «Dev». Master-grenen inneholder den siste stabile versjonen av applikasjonen, mens Dev-grenen inneholder den siste versjonen uansett tilstand. Master-grenen ble oppdatert de gangene viktige funksjonaliteter var implementert og testet, som regel en gang i uken.

Issues ble i dette prosjektet brukt som det stedet hvor man hadde oversikten over hva som måtte gjøres. Nye punkter ble lagt til etterhvert som prosjektet utviklet seg og markert ferdig når de var implementert.

\section{Chart.js}
Chart.js er et «open source»-bibliotek som gjør det enkelt å visualisere data i grafer ved hjelp av JavaScript. Etter man har definert hvilken type graf og hvilke data man skal ha i grafen vil biblioteket sørge for at grafen ser bra ut og alltid er lesbar. For eksempel, hvis man endrer oppsettet og gir mer rom til grafen på siden, vil den automatisk bli større. I tillegg er det også mulig å tilpasse det meste av innstillinger i forhold til tegning av grafen (e.g. farge, akse-beskrivelse).

Chart.js biblioteket bruker et <canvas> HTML5 node for å gjengi grafen, samt et script som spesifisere hvordan grafen skal tegnes. Data, akse-beskrivelser og andre innstillinger defineres enkelt i scriptet.

\subsection{Ng2-charts}
Ng2-charts er en utvidelse som gjør det enkelt å bruke Chart.js biblioteket i en Angular applikasjon. Etter man har importert ng2-charts inn i modulen i applikasjonene som den skal brukes i, kan man enkelt tegne en graf på liknende måte som man ville gjort i vanlig HTML/JS. Listing \ref{ng2chart} viser et minimalt eksempel hvor man kun har satt inn data og etiketter.  Vanligvis definerer man også diverse innstillinger (i.e. hvordan grafen skal se ut) i TypeScript-filen.

\begin{listing}[ht]
\begin{minted}{java}
// HTML file (componenent.html)
<canvas
      baseChart
      [chartType]="'line'"
      [datasets]="chartData"
      [labels]="chartLabels"
      [options]="chartOptions"
      [legend]="true">
</canvas>
\end{minted}

\begin{minted}{ts}
// TypeScript file (component.ts)
chartData = [
    { data: [330, 600, 260, 700], label: 'Account A' },
    { data: [120, 455, 100, 340], label: 'Account B' },
    { data: [450, 670, 800, 500], label: 'Account C' }
];
chartLabels = ['January', 'February', 'Mars', 'April'];
\end{minted}
\caption{Minimalt Ng2-charts oppsett}
\label{ng2chart}
\end{listing}

\section{Bootstrap}
Bootstrap er det nest mest fulgte prosjektet på GitHub. Det er et åpen kilde verktøy for å utvikle HTML, CSS og JavaScript. Hovedformålet med å bruke bootstrap er å spare tid på utseendet til applikasjonen ved å bruke klasser og funksjoner som allerede eksisterer i bootstrap. Man får tilgang til knapper, skjema, navigasjonslinjer og andre grensesnittkomponenter\cite{BootstrapAbout}.

\subsection{Tabeller}
I denne oppgaven ble bootstrap brukt til å utforme tabellen for brushfilene. Det ble laget en enkel tabell i HTML og \say{table} klassen fra bootstrap ble lagt til\cite{BootstrapTable}.

    <thead> <!-- table head -->

      </tr>
    </thead>

        <td>Ola</td> <!-- table data -->

      </tr>

        <td>Ola</td>

\subsection{Rutenettsystem}
Bootstrap har et rutenett system som gjør det enkelt å plassere elementer på rett plass i applikasjonen. Man deler siden inn i klassene container(beholder), row(rad) og col(kolonne) for å justere plasseringen. Disse radene og kolonnene er ikke synlige som i en tabell, men blir brukt som en pekepinn på hvor elementer vil dukke opp \cite{BootstrapGrid}.
\begin{itemize}
    \item Containers-klassen holder innholdet sentrert. Pikselbredden på skjermen blir justert slik at den blir tilpasset brukeren sin skjermstørrelse.
    \item Rows-klassen definerer en rad som kan inneholde flere kolonner. 
    \item Col-klassen er laget for kolonnene som skal inni radene. En nettside vil ha totalt 12 kolonner i x-retningen. Hvis man har to kolonner i en rad, vil den dele seg opp og ta 6 kolonner hver. Det er også mulig å manuelt velge hvor mange kolonner en vil at de elementene skal bruke. 
\end{itemize}
\begin{minted} {html}
<div class="container">
  <div class="row"> 
    <div class="col-sm">
      One of three columns
    </div>
    <div class="col-sm">
      One of three columns
    </div>
    <div class="col-sm">
      One of three columns
    </div>
  </div>
</div>
\end{minted}

\subsection{Knapper}
Bootstrap har sin egen button klasse der man kan definere hvilken type knappen er. Man har følgende typer: hoved-, sekundær-, suksess-, fare-, advarsel-, informasjon-, lys-, mørk- og linkknapp. Ut i fra hvilken type man velger vil bootstrap sette et passende utseende på knappen. Dette gjør det enklere for brukerne å oppfatte betydningen av knappen de skal trykke på.
